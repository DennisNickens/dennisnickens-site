Before You Start

This is not a quiz. There are no right answers. There is no winning.

What this is, is an invitation. An invitation to ask each other the questions you stopped asking. To remember why you chose each other. To make room for what God is still building in your marriage.

Pull one card. Read it aloud. Take turns answering. Listen all the way through before you respond. Stay soft.

Some questions will be easy. Some will open something you did not know was closed. Both are good.

Welcome to the quest.
